## 1. 项目概述

### 1.1 项目简介

eu搭子是一个游戏陪玩 / 休闲社交平台的前端项目。当前版本基于 **Vue 3 + Vite 5** 构建，是一个纯 SPA（单页应用），在浏览器端运行，**不依赖 UniApp 框架**。

项目采用组件化架构，核心页面已拆分为独立组件，通过底部 Tab 导航实现首页、广场、消息、我的四个主视图切换，并通过弹层系统实现发布动态、评论系统、用户资料查看、预约陪玩、陪玩师申请、钱包管理、个人资料编辑、帮助反馈、设置等次级功能。

### 1.2 产品定位

- **目标用户**：游戏玩家、陪玩师（陪陪）
- **核心价值**：连接游戏玩家与陪玩师，提供线上/线下陪玩服务
- **主要功能**：主页浏览、陪玩申请（线上/线下）、即时聊天、圈子互动、钱包管理、个人资料编辑

### 1.3 架构概览


### 3.2 Vue Router 路由架构

项目使用 Vue Router 4 (createWebHistory) 管理页面路由，53 条路由配置在 `router/index.js`。管理后台路由不在本项目中，位于独立的 `admin-frontend/` 项目。

#### 路由守卫配置

**公开路由**（无需登录即可访问）：`Login`、`Home`、`Search`、`Square`、`PostDetail`、`Preferred`、`Mine`、`Friend`

**路由钩子**：
- `beforeEach`：登录状态校验，非公开路由需登录
- `afterEach`：页面标题设置、预加载配置

## 4. 核心功能模块

### 4.1 用户认证模块

- **登录/注册**：手机号验证码登录（发送验证码 `/api/user/send-sms`、登录 `/api/user/login-mobile`）、密码登录、密码重置
- **第三方登录**：`/api/user/login-third`
- **用户信息**：获取用户信息 `/api/user/get`、更新资料 `/api/user/update`
- **Token管理**：JWT Token 存储与自动刷新
- **用户状态**：登录状态持久化（localStorage + Pinia）
- **参数校验**：统一的输入验证（手机号、密码、昵称等）
- **用户等级**：Lv.1-Lv.∞ 等级体系

### 4.2 聊天模块

- **即时通讯**：Socket.IO 实时消息推送，支持自动重连
- **会话列表**：显示最近聊天会话
- **私聊**：一对一文字聊天
- **消息类型**：文本、图片、语音、礼物、红包
- **图片/视频发送**：`ChatRoom.vue` 选用 `uploadFile` 直传 COS，消息体只存真实访问 URL（不再 `readAsDataURL` 内嵌整图字节，省带宽/存储）；本地预览用 `URL.createObjectURL`
- **消息状态**：发送中、已发送、已送达、已读、撤回（撤回图片/视频/语音同步清理底层存储与媒资登记）
- **撤回消息**：支持消息撤回
- **未读计数**：底部导航角标显示未读消息数
- **AI聊天**：虚拟用户陪聊功能

### 4.3 钱包模块

- **钱包概览**：显示金币余额
- **余额管理**：充值、提现、收入/支出记录
- **充值套餐**：选择充值套餐，微信支付
- **提现**：提现到微信/支付宝
- **交易记录**：收入记录、支出记录、提现记录
- **支付方式**：微信支付、支付宝、金币支付
- **VIP会员**：套餐购买、会员权益、等级加速
- **装扮商城**：头像框、身份标识等虚拟物品购买

### 4.4 社交模块

- **广场动态**：发布、浏览、点赞、评论、分享，支持图片预览
- **互动功能**：点赞、评论、关注，可从动态直接跳转预约
- **关注关系**：关注、取消关注、粉丝列表、关注列表
- **访客记录**：访客记录、隐身访问
- **用户资料**：头像、昵称、签名、相册、实名认证
- **个人统计**：关注、粉丝、获赞、访客数

### 4.5 陪玩服务模块

- **陪玩师申请**：选择线上/线下服务类型，资质审核
- **游戏选择**：支持王者荣耀、和平精英、英雄联盟等多款热门游戏
- **服务管理**：陪玩师端查看和管理自己的服务，创建、编辑、删除服务、服务数据看板
- **上下线切换**：陪玩师可切换在线/离线状态
- **预约系统**：预约时间、确认、取消、优先匹配
- **派单大厅**：游戏订单池、抢单、接单管理
- **订单状态**：待接单、进行中、已完成

### 4.6 音视频通话模块

- **语音通话**：一对一语音聊天（AudioCall.vue）
- **视频通话**：一对一视频聊天（VideoCall.vue）
- **双通道架构**：TRTC（腾讯云）为主通道，WebRTC（浏览器原生）为备选通道
- **统一入口**：`callService` 自动检测 TRTC 可用性并选择通道
- **WebRTC 信令**：通过 Socket.IO 交换 offer/answer/ICE candidate
- **通话状态**：呼叫中、已接通、已拒绝、已结束、无应答

### 4.7 错误处理模块

- **错误边界**：组件级错误捕获与优雅降级
- **统一错误码**：200/201/400/401/403/404/422/429/500/502 错误处理

### 4.8 卡密充值

- **卡密验证**：输入卡号和密码，调用 `/api/pay/validate-card` 验证

- **标签管理**：为虚拟用户分配标签

## 9. 错误码定义

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| 200 | 请求成功 | 正常处理 |
| 201 | 创建成功 | 正常处理 |
| 400 | 请求参数错误 | 提示用户检查输入 |
| 401 | 未授权/Token过期 | 跳转登录页 |
| 403 | 权限不足/账号禁用/禁言 | 提示对应原因 |
| 404 | 资源不存在 | 提示资源不存在 |
| 422 | 业务逻辑错误 | 显示后端返回的具体错误信息（如密码错误、用户不存在等） |
| 429 | 请求频率限制 | 提示操作过于频繁，稍后重试 |
| 500 | 服务器错误 | 提示系统繁忙 |
| 502 | 网关错误 | 提示稍后重试 |
