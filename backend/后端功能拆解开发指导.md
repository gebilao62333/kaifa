## 1. 项目概述

### 1.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端** | Vue 3 + Vite + Vue Router + Pinia | 组件化 SPA（58 个视图组件 + 27 个服务层文件），详见前端拆解文档 |
| **后端** | Node.js + Express | RESTful API + Socket.IO 实时通信 |
| **关系数据库** | MySQL + Sequelize | 业务主库，表前缀 `xn_`，43 个模型 |
| **文档数据库** | MongoDB + Mongoose | 核心数据库，用于高频写入场景；`config/mongo.js` 连接配置 |
| **实时通信** | Socket.IO + @socket.io/redis-adapter | 私聊/通话信令/P2P 信令，支持多实例横向扩展 |
| **音视频** | TRTC + WebRTC + P2P DataChannel | 1v1 音视频通话、WebRTC 直连、P2P 热内容取回 |
| **支付** | 微信支付 | 充值、VIP 下单、回调通知 |
| **文件存储** | 本地 multer + 腾讯云 COS 直传 | 图片/音频/视频上传，媒资统一登记 |
| **缓存** | Redis | 限流、Socket 适配器、短信防刷 |
| **AI** | LLM Service | 虚拟用户 AI 聊天 |

### 1.2 项目目录结构

```
kaifa/
├── frontend/                  # Vue 3 + Vite 前端 SPA（详见前端拆解文档）
├── backend/                   # Node.js + Express 后端
│   ├── server.js              # HTTP + Socket.IO 服务器入口（注册 /api/health）
│   └── src/
│       ├── config/            # 数据库/JWT/上传/Redis 等配置
│       ├── controllers/       # 控制器层 (22 个)
│       ├── models/
│       │   ├── mysql/         # Sequelize MySQL 模型 (43 个)
│       │   ├── mongo/         # Mongoose MongoDB 模型
│       │   └── index.js       # 模型统一导出
│       ├── routes/            # Express 路由文件 (30 个，含 index.js 加载器)
│       ├── services/          # 业务逻辑层 (27 个)
│       ├── middlewares/       # 认证/权限/限流/安全/校验/版本中间件 (7 个文件)
│       ├── socket/            # Socket.IO 实时通信 (index.js)
│       ├── healthcheck.js     # 健康探测（MySQL/Redis 连通性）
│       └── utils/             # 日志/响应/辅助工具
└── backend/后端功能拆解开发指导.md   # 本文档
```

### 2.31 Socket.IO 实时通信

**文件**: `backend/src/socket/index.js`（由 `server.js` 调用 `initializeSocket(io)` 初始化）

**认证机制**:
- `io.use` 中间件严格鉴权：从 `handshake.auth.token` 或 `query.token` 取令牌 → `verifyToken` 解码 → 校验用户存在，任何匿名/无效连接一律拒绝（`UNAUTHORIZED`）
- 连接后自动加入 `user:{userId}` 房间，并维护内存在线集合 `onlineUsers`（供 P2P 可达性探测）

**横向扩展**:
- 通过 `@socket.io/redis-adapter` 启用 Redis 适配器，多副本间私聊/通话/房间事件可跨实例广播；Redis 不可用时防御式降级为内存适配器（单实例）

**客户端事件（19 个）**:

| 事件 | 说明 |
|------|------|
| `private_message` | 私聊消息：落库 `xn_chat_log` 并更新双端会话与未读数，推送给 `user:{toId}`，回执 `private_message_ack` |
| `room_message` | 房间消息：仅实时广播至 `room:{roomId}`（不落库），回执 `room_message_ack` |
| `join_room` | 加入房间，成功回执 `join_room_success` |
| `leave_room` | 离开房间，成功回执 `leave_room_success` |
| `call_invite` | 通话邀请（支持 TRTC / WebRTC 标记） |
| `call_cancel` | 取消通话 |
| `call_reject` | 拒绝通话 |
