# 测试运行指南

## 环境要求

确保已安装以下软件：
- **Node.js**: v18.0.0 或更高版本
- **npm**: v8.0.0 或更高版本（通常随 Node.js 一起安装）

### 检查 Node.js 和 npm 是否已安装

```bash
node --version
npm --version
```

## 快速开始

### 步骤 1: 进入后端目录

```bash
cd /home/devbox/project/kaifa/backend
```

### 步骤 2: 安装依赖

```bash
npm install
```

### 步骤 3: 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env` 文件，配置以下内容（测试环境可以使用默认值）：

```env
# 服务器配置
PORT=3000
NODE_ENV=development

# JWT 配置
JWT_SECRET=your-secret-key-change-in-production
JWT_EXPIRES_IN=7d

# 数据库配置（测试时可使用默认配置）
DB_HOST=localhost
DB_PORT=3306
DB_NAME=duoke_peer
DB_USER=root
DB_PASSWORD=

# MongoDB
MONGO_URI=mongodb://localhost:27017/duoke_peer

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379
```

### 步骤 4: 运行测试

#### 运行所有测试

```bash
npm test
```

#### 运行测试并生成覆盖率报告

```bash
npm run test:coverage
```

#### 监听模式（开发时使用）

```bash
npm run test:watch
```

## 测试命令详解

### npm test
运行所有测试文件（*.test.js 和 *.spec.js）

### npm run test:coverage
运行测试并生成覆盖率报告，包含：
- **文本报告**: 终端中显示
- **HTML 报告**: `coverage/lcov-report/index.html`
- **JSON 摘要**: `coverage/coverage-summary.json`

### npm run test:watch
监听文件变化，自动重新运行测试（适合开发阶段）

## 运行特定测试

### 运行特定文件
```bash
npx jest tests/unit/utils/helper.test.js
```

### 运行特定目录
```bash
npx jest tests/unit/
npx jest tests/integration/
```

### 运行匹配模式的测试
```bash
npx jest --testNamePattern="should"
npx jest --testNamePattern="gift"
```

## 调试测试

### 打开 Node.js 调试器
```bash
npm test -- --inspect-brk
```

### 查看详细输出
```bash
npm test -- --verbose
```

### 在失败时停止
```bash
npm test -- --bail
```

## 常见问题解决

### 问题 1: npm install 失败

```bash
npm cache clean --force
rm -rf node_modules
npm install
```

### 问题 2: 测试找不到模块

```bash
cd /home/devbox/project/kaifa/backend
npm install
```

### 问题 3: 测试超时

编辑 `jest.config.js`:
```javascript
module.exports = {
  testTimeout: 30000,
  // ...
};
```
